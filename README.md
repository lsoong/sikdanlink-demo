# 식단링크 데모 (sikdanlink-demo)

인바디 수치를 넣으면 **기초대사량 · 목표 칼로리 · 주간 탄단지**를 계산해 주는 정적 웹 데모입니다.

👉 **https://lsoong.github.io/sikdanlink-demo/**

## 이 저장소는 무엇인가

**빌드 산출물만 담는 배포용 미러입니다.** 소스 코드는 비공개 저장소에 있고, 여기에는
빌드된 결과물(`index.html`, `assets/`, `knowledge/`)만 올립니다. GitHub Free 플랜은
비공개 저장소에 Pages를 쓸 수 없어서 배포 산출물만 따로 공개합니다.

| 여기 있는 것 | 여기 없는 것 |
|---|---|
| 컴파일·번들된 JS/CSS (`assets/`) | TypeScript 소스, 테스트 코드 |
| 지식베이스 JSON (`knowledge/`) | 커밋 이력, 이슈, 설계·기획 문서 |
| `index.html` | 빌드 설정, 내부 운영 문서 |

정적 사이트라 브라우저가 받는 파일(번들 JS와 지식베이스 JSON)은 어차피 누구나 볼 수
있습니다. 이 저장소를 공개해서 추가로 열리는 것은 없습니다.

## 개인정보

- **입력한 신체 수치는 서버로 전송되지 않습니다.** 계산은 전부 브라우저 안에서 끝나고,
  저장은 브라우저 `localStorage` 하나뿐입니다. 백엔드가 없습니다.
- 화면의 초기 입력값은 **데모용 가상 수치**입니다(실제 인물의 인바디 데이터가 아닙니다).

## 계산 근거

활동계수·목표별 칼로리 조정·매크로 배분과 방법론 7종은 문헌 근거 기반 지식베이스에서
생성합니다(`knowledge/*.json` 의 `_provenance` 필드 참고). 다이어트 방법론 비교의 전제는
아래 문헌을 따릅니다.

- Johnston BC, et al. (2014). *JAMA* 312(9):923-933. — RCT 48건 7,286명, 이름 붙은
  다이어트 간 감량 차이는 임상적으로 미미
- Gardner CD, et al. (2018) DIETFITS. *JAMA* 319(7):667-679.
- Sacks FM, et al. (2009) POUNDS LOST. *N Engl J Med* 360(9):859-873.

## ⚠️ 의학적 면책

이 데모는 **정보 제공용이며 의학적 조언이 아닙니다.** 계산 결과는 일반 인구 집단을
대상으로 한 추정식이며, 개인의 질환·복약·임신·성장기 여부를 고려하지 않습니다.
식단이나 운동을 실제로 바꾸기 전에 의사·임상영양사 등 자격 있는 전문가와 상의하십시오.

## 갱신 방법

비공개 저장소에서 `npm run build` 후 산출물을 이 저장소 루트로 미러링합니다.
직접 이 저장소에 커밋하면 다음 배포 때 덮어써집니다.
